# Web notifications — Pilot v1.7.9

«Окно в Китай» поддерживает персональные уведомления о новых материалах.

## Что настраивает пользователь

- общий переключатель уведомлений;
- компании и бренды: SHACMAN, GWM, EVOLUTE, VOYAH, Моторинвест, ЭВИА и другие;
- сегменты автопрома: коммерческий транспорт, легковые автомобили, EV/NEV, компоненты и поставщики, производство и локализация, логистика, регулирование/геополитика, рынок/продажи, технологии/ADAS;
- вариант «Весь автопром» для получения всех новых отраслевых материалов.

Настройки сохраняются в существующем пользовательском профиле через `/api/user/preferences`. Новые уведомления формируются из актуального агрегата новостей и выдаются через `/api/user/notifications`.

## Два уровня доставки

1. Внутренний колокольчик работает в web-интерфейсе и показывает непрочитанные уведомления.
2. Системное уведомление браузера/ОС используется при наличии Notification API, разрешения пользователя и secure context (HTTPS или localhost). Service Worker открывает связанный материал по клику.

Клиент проверяет новые пользовательские уведомления раз в 60 секунд. Существующий серверный scheduler обновляет новостной агрегат по своей политике пилота.

## Выключение

Если `notificationsEnabled=false`, новые персональные уведомления для пользователя не генерируются. Уже созданная история остаётся доступной до стандартного срока retention.

## Ограничение пилота

Это web-notification режим, а не серверный Web Push. Когда браузер/PWA полностью закрыты и остановлены ОС, гарантированная фоновая доставка не выполняется. Для такого режима потребуется отдельная корпоративная Web Push/VAPID-конфигурация и хранение push-subscriptions.
