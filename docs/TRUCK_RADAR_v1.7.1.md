# Окно в Китай — Truck Radar v1.7.1

## Назначение

Truck Radar — отдельный intelligence-контур по коммерческому транспорту Китая и России. Он не подменяет рыночную статистику и не называет количество новостей «долей рынка». Его задача — быстро показать значимые сигналы и объяснить, почему они важны для R&D, закупок, производства, логистики и руководства.

## Сегменты

- HCV · тяжёлые грузовики;
- MCV · среднетоннажные;
- LCV · лёгкие коммерческие автомобили;
- седельные тягачи;
- самосвалы / строительная техника;
- шасси / специальная техника.

## Силовые установки

Truck Radar отдельно помечает:

- diesel;
- LNG / CNG;
- battery electric;
- battery swap;
- hydrogen / fuel cell;
- hybrid.

Это позволяет быстро отделять обычный продуктовый шум от структурных изменений в энергетической архитектуре коммерческого транспорта.

## Business Intelligence Ranking

Каждый материал оценивается по совокупности признаков:

1. свежесть;
2. авторитет источника;
3. регуляторный сигнал;
4. локализация;
5. поставки;
6. технология;
7. рынок;
8. инвестиции;
9. качество/риски;
10. экспорт и торговля;
11. наличие truck-сегмента, бренда и новой силовой технологии;
12. кросс-рыночность Китай ↔ Россия.

Результат: `score 0..100` и уровень `Критично / Высокий приоритет / Наблюдение / Фон`.

## Для кого важно

Система отдельно рассчитывает релевантность материала для:

- Руководства;
- R&D;
- Закупок;
- Производства;
- Логистики.

Truck-сигналы автоматически получают дополнительный вес для логистики и закупок, а технологические EV/H₂/battery-swap сигналы — для R&D.

## «Почему важно» и «Что проверить»

Truck Radar не генерирует свободный прогноз. Он формирует объяснение из обнаруженных фактических признаков материала. Для cross-market China ↔ Russia карточка предлагает проверить:

- сертификацию;
- локализацию;
- TCO;
- сервис;
- доступность компонентов;
- применимость к российским маршрутам и условиям эксплуатации.

## UI

Новый маршрут: `/trucks`.

На странице есть:

- Китай / Россия / Китай ↔ Россия filters;
- HCV / MCV / LCV / тягачи / самосвалы / шасси filters;
- поиск по бренду, модели и технологии;
- live source status;
- Truck Brand Radar;
- карточки с business score;
- `Почему важно`;
- `Что проверить`;
- ссылки на первоисточник.

## Integrity rule

Количество упоминаний бренда в Truck Radar — это **не рыночная доля**. UI явно сообщает об этом. Реальные продажи/доли должны поступать из статистических источников и показываться отдельно от news-signal counts.
